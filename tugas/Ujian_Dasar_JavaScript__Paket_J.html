Ujian Dasar JavaScript — Paket J

Topik: Variabel • Tipe Data • Operator • Percabangan • Array • Perulangan

Petunjuk: Baca setiap soal cerita dengan teliti. Tentukan data yang dibutuhkan, lalu buat program JavaScript untuk menyelesaikan masalahnya.

Ketentuan Pengerjaan: Nilai diberikan dari proses program, bukan hanya tampilan akhir. Simpan data awal dari cerita, lakukan proses yang diminta, lalu tampilkan hasil akhirnya. Jangan menulis nilai hasil atau pesan akhir secara langsung.

01

Proyek aplikasi bernama “AbsensiKu” memiliki versi 1, 6 halaman, dan status uji coba true. Satu halaman baru ditambahkan. Tampilkan data proyek. Ketentuan proses: Simpan data awal yang ada pada cerita. Lakukan setiap perubahan secara berurutan, lalu tampilkan kondisi akhirnya. Nilai akhir tidak boleh ditulis langsung.

Output yang Diharapkan: 

Aplikasi: AbsensiKu
Versi: 1
Halaman: 7
Uji Coba: true
