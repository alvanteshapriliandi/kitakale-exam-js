Ujian Dasar JavaScript — Variabel, Operator, dan Percabangan (Paket L)

Topik: Variabel • Operator Aritmatika • Operator Perbandingan • Operator Logika • Percabangan (if, else, else if)

Petunjuk: Baca setiap soal cerita dengan teliti. Tentukan data yang dibutuhkan, lalu buat program JavaScript untuk menyelesaikan masalahnya. Materi soal hanya variabel, operator, dan percabangan.

Ketentuan Pengerjaan: Nilai diberikan dari proses program, bukan hanya tampilan akhir. Simpan data awal dari cerita, lakukan proses yang diminta, lalu tampilkan hasil akhirnya. Jangan menulis nilai hasil atau pesan akhir secara langsung.

01

Tim debat menyimpan nama tim “Argumen”, jumlah anggota 8, jumlah motion 3, dan status siap false. 2 anggota baru bergabung. Tampilkan data tim terbaru. Ketentuan proses: Simpan data awal yang ada pada cerita. Lakukan setiap perubahan secara berurutan, lalu tampilkan kondisi akhirnya. Nilai akhir tidak boleh ditulis langsung.

Output yang Diharapkan: 

Tim: Argumen
Anggota: 10
Motion: 3
Siap: false
