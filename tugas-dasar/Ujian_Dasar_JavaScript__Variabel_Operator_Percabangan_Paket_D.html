Ujian Dasar JavaScript — Variabel, Operator, dan Percabangan (Paket D)

Topik: Variabel • Operator Aritmatika • Operator Perbandingan • Operator Logika • Percabangan (if, else, else if)

Petunjuk: Baca setiap soal cerita dengan teliti. Tentukan data yang dibutuhkan, lalu buat program JavaScript untuk menyelesaikan masalahnya. Materi soal hanya variabel, operator, dan percabangan.

Ketentuan Pengerjaan: Nilai diberikan dari proses program, bukan hanya tampilan akhir. Simpan data awal dari cerita, lakukan proses yang diminta, lalu tampilkan hasil akhirnya. Jangan menulis nilai hasil atau pesan akhir secara langsung.

01

Dapur sekolah menyimpan nama dapur “Rasa Kelas”, jumlah kompor 4, porsi siap 50, dan status buka true. 13 porsi terjual. Tampilkan data dapur setelah penjualan. Ketentuan proses: Simpan data awal yang ada pada cerita. Lakukan setiap perubahan secara berurutan, lalu tampilkan kondisi akhirnya. Nilai akhir tidak boleh ditulis langsung.

Output yang Diharapkan: 

Dapur: Rasa Kelas
Kompor: 4
Porsi: 37
Buka: true

02

Ketentuan proses: Simpan data awal yang ada pada cerita. Lakukan setiap perubahan secara berurutan, lalu tampilkan kondisi akhirnya. Nilai akhir tidak boleh ditulis langsung.

Output yang Diharapkan:

Bahan: 11
Langkah: 6
Diuji: false
