Ujian Dasar JavaScript — Variabel, Operator, dan Percabangan (Paket B)

Topik: Variabel • Operator Aritmatika • Operator Perbandingan • Operator Logika • Percabangan (if, else, else if)

Petunjuk: Baca setiap soal cerita dengan teliti. Tentukan data yang dibutuhkan, lalu buat program JavaScript untuk menyelesaikan masalahnya. Materi soal hanya variabel, operator, dan percabangan.

Ketentuan Pengerjaan: Nilai diberikan dari proses program, bukan hanya tampilan akhir. Simpan data awal dari cerita, lakukan proses yang diminta, lalu tampilkan hasil akhirnya. Jangan menulis nilai hasil atau pesan akhir secara langsung.

01

Koperasi sekolah menyimpan nama kios “Serba Ada”, nomor loker 7, stok pulpen 40, dan status buka true. 9 pulpen terjual. Tampilkan data kios setelah penjualan. Ketentuan proses: Simpan data awal yang ada pada cerita. Lakukan setiap perubahan secara berurutan, lalu tampilkan kondisi akhirnya. Nilai akhir tidak boleh ditulis langsung.

Output yang Diharapkan: 

Kios: Serba Ada
Loker: 7
Pulpen: 31
Buka: true

02

Tampilkan data lakon terbaru. Ketentuan proses: Simpan data awal yang ada pada cerita. Lakukan setiap perubahan secara berurutan, lalu tampilkan kondisi akhirnya.
